# Ecommerce design reference

The Northstar demo has shifted from an ecommerce storefront to an inventory operations dashboard. For active product work, focus on stock accuracy, traceable movements, replenishment signals, and operational workflows. This document remains as a reference in case the storefront returns.

When working on a storefront, design the complete journey from discovery and product evaluation through cart and checkout. Use semantic, accessible controls, clear stock/price information, meaningful empty and error states, and responsive layouts. Keep scrolling predictable; sticky controls should not obscure content or keyboard focus. Establish semantic color tokens and verify contrast rather than relying on color alone.
